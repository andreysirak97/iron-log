# IRON LOG V3.5 — GitHub Pages

Обновление: вместо подъёма ног в висе в Дне А и Дне Б — подъём коленей/ног в тренажёре с опорой на предплечья (капитанский стул). Добавлены новая анатомическая иллюстрация и инструкция.

1. В установленном приложении экспортируйте резервную копию JSON.
2. Загрузите в корень репозитория GitHub все файлы, включая папку `images/` и `images/captainschair.webp`.
3. Подтвердите Commit changes, дождитесь публикации Pages и перезапустите PWA.
4. Проверьте карточку техники и историю.

Сохраняется ключ localStorage `ironlog_v2`, предыдущая история не изменяется. Автоматически меняются названия только стандартных упражнений с ID `a_core` и `b_core` и известными прежними названиями. Пользовательские переименования не перезаписываются.

Изображение — художественная анатомическая иллюстрация, не эталон биомеханики. Системные уведомления PWA при блокировке экрана не гарантируются.
