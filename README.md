# IRON LOG V4.0 — обновление GitHub Pages

1. Открой IRON LOG на телефоне и скачай резервную копию через ⇧.
2. Распакуй ZIP, загрузи содержимое архива в корень репозитория `andreysirak97/iron-log` (включая все файлы из `images/`), сделай Commit changes.
3. Дождись публикации GitHub Pages и перезапусти установленное PWA. При необходимости обнови страницу в Chrome.

## Новое
- Между подходами остаётся текущая настройка пользователя (если она уже была 90 секунд, она сохраняется).
- После отметки последнего подхода упражнения автоматически начинается 150-секундный отдых, если дальше есть незавершённые упражнения.
- Общий таймер запускается при нажатии «Начать» или при отметке первого выполненного подхода; время хранится между перезапусками приложения.
- История: отчёт для ChatGPT (одна тренировка, последние 30 дней, вся история), копирование в буфер и TXT.
- Итоговый экран: длительность, подходы, тоннаж, примерные калории по MET.
- Масса тела и MET настраиваются в ⚙. Для старых тренировок без записанной длительности калории не рассчитываются.

## Ограничения
PWA не гарантирует сигнал таймера на заблокированном Android. Расход калорий по MET — грубая оценка, не измерение. Все данные сохраняются локально в `ironlog_v2`; удаление данных сайта уничтожит их без резервной копии.
