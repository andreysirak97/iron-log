# IRON LOG V2.1

Android-friendly PWA-дневник силовых тренировок. В основе — упражнения и стартовые значения из присланного HTML пользователя.

## Методика и обновления 2.1
- Два занятия Full Body A/B в неделю; оба включают основные движения для ног, спины и груди.
- Добавлены икры и мышцы кора в оба дня: стоячие/сидячие подъёмы на носки и упражнения на сгибание корпуса.
- Добавлены жим гантелей на наклонной скамье и жим ногами в День Б, чтобы оба занятия охватывали грудь и ноги.
- Двойная прогрессия теперь ориентируется на первый рабочий подход, как в видео: достиг верхней границы диапазона при близости к техническому отказу — можно прибавить минимальный шаг веса; в следующих подходах допустимо снижение до 2 повторений.
- При обновлении существующей установки новые упражнения добавляются автоматически, прежние веса и история сохраняются.

## Возможности
- День А / День Б с исходными упражнениями, подходами и стартовыми весами.
- Диапазон повторений по умолчанию 8–12.
- Подсказка двойной прогрессии: увеличение веса предлагается по первому рабочему подходу при достижении верхней границы диапазона и сохранении техники.
- Запись веса, повторений, отметка подходов и необязательный RIR 0–5.
- Добавление/удаление подходов, редактирование упражнений и диапазона, изменение порядка кнопками и перетаскиванием.
- Автотаймер отдыха, пауза, шаг ±30 секунд, вибросигнал по завершении (если поддерживается устройством).
- Автосохранение текущих значений в localStorage.
- История с деталями, статистика объёма и график рабочего веса.
- Экспорт/импорт JSON.
- PWA manifest и Service Worker для кэширования интерфейса.

## Установка на Android
Для установки как PWA проект должен быть размещён на HTTPS-хостинге. Распакуйте архив, загрузите все файлы из папки `iron_log_v2` на HTTPS-хостинг, откройте адрес в Chrome Android и выберите «Установить приложение» / «Добавить на главный экран». При первом запуске откройте приложение онлайн, чтобы Service Worker закэшировал ресурсы.

Открытие `index.html` как локального файла не обеспечивает установку PWA и работу Service Worker.

## Важные оговорки
- Приложение хранит данные в браузере устройства. Регулярно экспортируйте JSON-бэкап.
- Стартовые упражнения/веса — исходные значения из HTML, не медицинская или индивидуальная рекомендация.
- Подсказка двойной прогрессии — вспомогательный ориентир. Увеличивайте нагрузку только при сохранении техники и контроля.
- Восстановление резервных копий совместимо с форматом IRON LOG V2.1; старые данные из оригинального прототипа автоматически не мигрируются.
