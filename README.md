# IRON LOG V4.4 — GitHub Pages

Обновление Full Body A/B для двух занятий в неделю.

## Программа
- День А: жим ногами, жим гантелей лёжа, горизонтальная тяга, сгибание ног сидя, махи в стороны, бицепс, икры стоя, прямые ноги в упоре.
- День Б: румынская тяга, тяга верхнего блока, наклонный жим гантелей, жим гантелей сидя, жим ногами, трицепс на блоке, икры сидя, прямые ноги в упоре.
- Каждое упражнение: **1 разминочный + 2 рабочих подхода** по умолчанию. Разминка не учитывается в рабочем объёме и не запускает отдых.
- Веса разминочного подхода не задаются автоматически. Подбирай лёгкую нагрузку; перед тяжёлой румынской тягой и жимом ногами могут понадобиться дополнительные ступени разминки.

## Установка
1. Сначала выгрузи резервную копию из текущего приложения.
2. Загрузи все файлы и папку images в корень репозитория GitHub Pages.
3. После обновления открой приложение и нажми «Установить новую программу A/B». История сохранится, но текущие незавершённые подходы заменятся. Рабочие веса совпадающих упражнений переносятся.
4. Проверь оба дня, таймеры и технику упражнений.

Ключ хранения истории: ironlog_v2. Не удаляй данные сайта. PWA может не уведомить при заблокированном телефоне.
