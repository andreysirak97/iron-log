# IRON LOG V3.3 — обновление для GitHub Pages

## Новое
- 16 анатомических иллюстраций в стиле гравюры с выделенными мышцами.
- 4 вкладки: Анатомия, Движение, Техника, Ошибки.
- Отдельные варианты для альтернативных упражнений.
- Удалены ссылки ACE. YouTube — русскоязычный поиск, а не подборка проверенных роликов.
- Иллюстрации художественные, не заменяют проверку техники тренером; вкладка «Движение» содержит текстовые фазы, **не анимацию**.
- Существующий таймер и настройки уведомлений сохранены.

## Установка / обновление
1. В установленном IRON LOG экспортируйте резервную копию JSON.
2. Распакуйте ZIP, загрузите **все файлы и папку images с 16 webp** в корень репозитория GitHub Pages, заменяя прежние.
3. Дождитесь публикации, откройте сайт и перезапустите PWA. При необходимости закройте приложение полностью и откройте снова.
4. Не удаляйте данные сайта: история хранится в localStorage на устройстве.

## Ограничения
- Художественные анатомические иллюстрации созданы ИИ, могут содержать неточности и не показывают точную траекторию.
- При заблокированном Android уведомления PWA по-прежнему не гарантированы.
- Автоматизированная проверка синтаксиса не заменяет тестирования на телефоне.
