# IRON LOG V3.1 — техника и улучшенный таймер (PWA)

## Обновление через GitHub Pages
1. В установленном IRON LOG нажмите ⇧ → «Скачать резервную копию» и сохраните JSON.
2. Распакуйте ZIP. Откройте https://github.com/andreysirak97/iron-log → Code → Add file → Upload files.
3. Загрузите **пять файлов из архива** непосредственно в корень репозитория (не папку). Подтвердите замену, нажмите Commit changes.
4. Подождите публикацию. Откройте https://andreysirak97.github.io/iron-log/ в Chrome и перезапустите установленное приложение. Иногда требуется обновить страницу дважды для обновления service worker.
5. Не удаляйте данные сайта. Если история отсутствует, используйте ⇧ → «Восстановить из файла».

## Таймер и уведомления
- Таймер считает оставшееся время по абсолютному времени окончания, поэтому при возвращении в приложение не отстаёт из-за приостановки фоновых интервалов.
- Если приложение продолжает выполнять код, при завершении отдыха срабатывают звук (после взаимодействия с приложением), вибрация (если поддерживается) и попытка системного уведомления (если разрешено).
- Настройки по умолчанию: звук включён, вибрация включена, повтор через 30 секунд выключен.
- В приложении откройте ⚙ → «Разрешить уведомления» и подтвердите запрос Android/Chrome. Разрешите уведомления для сайта/приложения в настройках Android.
- **Важно:** Android может приостановить или завершить PWA при блокировке. Системное уведомление, звук и вибрация в этот момент НЕ гарантированы. Service Worker без push-сервера не может надёжно самостоятельно разбудить приложение в заданную секунду. Эта версия не использует push-сервер.
- Таймер сохраняет конечное время в localStorage. При повторном открытии в пределах периода отсчёт восстанавливается; если срок прошёл в закрытом приложении, таймер сбрасывается без запоздалого сигнала.

## Совместимость
- Сохранён прежний ключ данных `ironlog_v2` и формат резервной копии: история, веса и программа остаются на месте при обновлении с того же адреса и в той же PWA.
- Встроена библиотека техники V3 (16 вариантов) со схемами и анимациями. Ссылки на видео — поисковые, индивидуальная проверка видео не проводилась.
- Для максимальной надёжности сигналов при заблокированном телефоне требуется нативное Android-приложение.
