# IRON LOG V4.2 — GitHub Pages

Распакуйте содержимое архива в корень репозитория (включая images). Сначала экспортируйте резервную копию JSON из установленного приложения. После обновления пользователи старой программы увидят кнопку «Установить новую программу A/B». Новая программа не применяется автоматически, чтобы не потерять незавершённые подходы. При выборе кнопки история сохраняется, веса упражнений с совпадающими ID переносятся, текущие незавершённые подходы заменяются шаблоном.

День A: жим ногами 3×8–12, жим гантелей лёжа 3×8–12, горизонтальная тяга 3×8–12, сгибание ног сидя 2×10–15, махи в стороны 2×12–20, бицепс 2×8–12, икры стоя 2×10–15, прямые ноги в упоре 2×8–15. Всего 19 подходов.

День B: румынская тяга 3×8–10, тяга верхнего блока 3×8–12, наклонный жим гантелей 3×8–12, жим гантелей сидя 2×8–12, жим ногами 2×10–15, трицепс 2×10–15, икры сидя 2×12–20, прямые ноги в упоре 2×8–15. Всего 19 подходов.

Два новых оригинальных анатомических рисунка: images/legcurl.webp и images/lateral.webp. Таймер кардио отдельный. Разминка не входит в рабочие подходы и тоннаж. Подсказки ориентировочные. Уведомления на заблокированном экране Android не гарантируются.
